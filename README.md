# Smart Grid App (Практичні роботи №1-4)

Навчальний Android-проєкт, розроблений для демонстрації основ створення мобільних застосунків із використанням сучасних декларативних підходів. Застосунок реалізує розрахунок параметрів системи розподілу електроенергії (Smart Grid).

**Автор:** Анастасія Кузьміна, студентка КПІ (Інженерія програмного забезпечення)  
**Тема/Варіант:** Система розподілу електроенергії (Smart Grid)

## Опис проєкту
Проєкт об'єднує в собі вимоги чотирьох практичних робіт:
1. Створення базового застосунку та налаштування середовища Android Studio.
2. Організація модульної структури проєкту та виділення бізнес-логіки в окремі класи (`data/SmartGridCalculator.kt`).
3. Побудова користувацького інтерфейсу (UI) за допомогою фреймворку **Jetpack Compose** (робота з layout, текстом та кнопками).
4. Створення екрану авторизації та реєстрації користувачів із валідацією введених даних і управлінням станами (State).

## Основний функціонал
* **Екран авторизації/реєстрації:** Користувацький інтерфейс для входу інженера в систему з перевіркою заповненості полів.
* **Калькулятор потужності мережі:** Інтерактивний розрахунок необхідної потужності енергомережі на основі трьох параметрів:
  * Загальне навантаження споживачів (кВт)
  * Ефективність ліній електропередач (%)
  * Необхідна резервна потужність (%)
* **Динамічний UI:** Миттєве оновлення результатів на екрані без перезавантаження завдяки реактивним станам (`remember`, `mutableStateOf`).

## Стек технологій
* **Мова:** Kotlin
* **Інтерфейс:** Jetpack Compose, Material Design 3
* **Збірка:** Gradle (Kotlin DSL)
* **Архітектура:** Розділення логіки (`data`) та відображення (`composables`)
